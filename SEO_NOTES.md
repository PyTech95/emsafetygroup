# SEO, GEO & AEO — E.M Safety (October 2026)

## What's in the code
**Technical SEO**
- Every page has its own title (≈ 60 characters), meta description (≈ 150 characters), canonical URL, Open Graph and Twitter tags, and a 1200×630 share image (`/assets/images/og-emsafety.jpg`).
- The canonical domain is `https://emsafetygroup.it`, because both `www` and non-`www` serve the site today. To change it, set `REACT_APP_PUBLIC_SITE_URL` (frontend) and `PUBLIC_SITE_URL` (backend).
- `robots.txt` blocks `/admin`, `/verifica/` (pages with personal data) and `/api/certificates/`. It lists both sitemaps.
- Sitemaps:
  - `/sitemap.xml` (static pages, generated at build time);
  - `/api/sitemap.xml` (live course and story pages, generated by the backend).
- The header and footer menus are now real links, so Google can follow them. Before, they were buttons Google couldn't follow.
- Unknown URLs show a proper 404 page with `noindex`. Before, they redirected to the homepage, which Google treats as a soft 404.
- The admin area and certificate result pages are `noindex`. The certificate API also sends an `X-Robots-Tag: noindex` header.
- Performance:
  - images went from 5.1 MB to 2.5 MB;
  - an unused, render-blocking icon font was removed;
  - a web app manifest and theme colour were added.

**Structured data (JSON-LD, schema.org)**
- **On every page:** Organization / LocalBusiness (ProfessionalService + EducationalOrganization) with both offices, phone, email, VAT number, opening hours, areas served, affiliations and service catalogue; plus WebSite.
- **On specific pages:**
  - WebPage / AboutPage / ContactPage with BreadcrumbList;
  - FAQPage on `/faq`, `/corsi` and `/verifica-attestato`;
  - Service list on `/servizi`;
  - Course catalogue on `/corsi`;
  - Course + EducationEvent (date, place, trainer, price) on every course page;
  - Article on every success story.

**GEO / AEO (AI search: ChatGPT, Perplexity, Claude, Google AI Overviews)**
- **Pre-rendered HTML:** `yarn build` now runs `scripts/seo-build.js` after the build. It writes an HTML file per page with the real heading, text, services, course catalogue, FAQ and contact details. AI crawlers that don't run JavaScript can read the site. React replaces this content when the page loads, so visitors see no difference.
- **`/llms.txt`:** a plain-text summary of the company, services, courses, certificate verification and FAQ for AI assistants.
- **`robots.txt`:** explicitly allows the main AI crawlers (GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot, Google-Extended and others).
- **Answer-first content:** Q&A blocks on `/corsi` and `/verifica-attestato`, and a new "Catalogo corsi" section on `/corsi`. FAQ answers are now always in the page HTML; before, they only existed while opened.

**Editable from the admin panel**
- Admin → Testi Sito → "SEO · Titoli e descrizioni Google": title and description for every page.

## After deploying (one-off, about 20 minutes)
1. **Google Search Console** (https://search.google.com/search-console):
   - Add a **Domain property** for `emsafetygroup.it`. This covers www and non-www.
   - Verify it with the DNS TXT record Google gives you.
   - Alternative: create a URL-prefix property and set `REACT_APP_GOOGLE_SITE_VERIFICATION=<code>` in `frontend/.env` before building. The meta tag is then added to every page.
2. **Sitemaps** → submit `sitemap.xml` and `api/sitemap.xml`.
3. **URL Inspection** → request indexing for `/`, `/servizi`, `/corsi` and `/verifica-attestato`.
4. **Bing Webmaster Tools:** import the site from Search Console. Bing data is also used by ChatGPT search. Optional: `REACT_APP_BING_SITE_VERIFICATION`.
5. **Hosting:** if possible, set a 301 redirect from `www.emsafetygroup.it` to `emsafetygroup.it`. The canonical tags already handle it, but a redirect is cleaner.
6. **Google Business Profile:** claim or verify both offices (Treviso and Milano). Use exactly the same name, address and phone as the website.
7. **Validate:**
   - https://search.google.com/test/rich-results on a course page and on `/faq`;
   - https://validator.schema.org.

Note: the dev server (`yarn start`) doesn't run the post-build step. Only `yarn build` does.
